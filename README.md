# Freelancing Hub

A full stack freelancing platform built using Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- User Authentication (Login & Signup)
- Employer Dashboard
- Employee Dashboard
- Project Posting System
- Project Applications
- Task Management
- Progress Tracking
- Resource Sharing
- Profile Management

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Flask (Python)

### Database
- MySQL (phpMyAdmin)

## Project Structure

```bash
freelancing_hub/

```

## How to Run the Project

### Step 1: Clone Repository

```bash
git clone https://github.com/sumukhskowshik/freelancing_hub.git
```

### Step 2: Open Project

```bash
cd freelancing_hub
```

### Step 3: Install Dependencies

```bash
pip install flask mysql-connector-python
```

### Step 4: Start XAMPP

- Start Apache
- Start MySQL

### Step 5: Import Database

- Open phpMyAdmin
- Create database
- Import SQL file

### Step 6: Run Flask App

```bash
python app.py
```
